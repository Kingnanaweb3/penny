## Notes on existing tests

No existing test in `tests/payments.test.js` was changed. The test `"fee is 1.5 percent of the charge"` asserts `r.fee === r.amount * 0.015`. This still holds because `charge()` still returns `fee: amount * FEE_RATE` — the fee value is computed for the return value but no longer posted to the ledger. The test was documented as asserting buggy behavior in the P1 note; now that P4 is fixed, the ledger posting no longer happens, but the returned value remains `amount * 0.015`, so the assertion is coincidentally still correct as a description of what settlement will cost.
